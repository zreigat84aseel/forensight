# Forensight

**Automated Phishing Email Forensics & Campaign Analysis**

Forensight is a phishing email forensics platform that analyzes suspicious emails (.eml), independently verifies sender authentication, detects lookalike domains and QR-code phishing, performs static attachment analysis, clusters related emails into campaigns, and generates ready-to-use detection content (YARA, Sigma, STIX).

> Built as part of the CyberFox Society Cybersecurity Research & Development Internship.

## Status
🚧 Under active development

## Safety
Forensight performs **static analysis only**. It never opens attachments or visits URLs from analyzed emails. Malicious samples are never committed to this repository.
